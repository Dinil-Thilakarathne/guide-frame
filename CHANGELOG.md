# Changelog

All notable changes to GuideFrame are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Open-source contribution, security, community, CI, and AI-agent guidance.
- Root formatting and linting standards.

## [0.2.0-beta.5] - Unreleased

### Added

- Option/Alt-drag guide duplication.
- Shift-drag marquee selection and Shift-click additive selection.
- Batch deletion and a compact Clear menu for selected, horizontal, vertical, or all guides.
- Shift+Z guide-history undo.
- Keyboard nudging for selected guides with grouped undo behavior.
- Full-screen Vite interaction test surface.

### Changed

- Command/Ctrl-drag now temporarily bypasses snapping.
- Guide selection supports multiple unlocked guides while preserving locked-guide protection.

# Security Policy

## Supported versions

GuideFrame is currently in beta. Security fixes are applied to the latest published beta. Older beta
versions may not receive patches.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/Dinil-Thilakarathne/guide-frame/security/advisories/new)
to share the affected package and version, impact, reproduction steps, and any suggested mitigation.
If private reporting is unavailable, contact the maintainer privately through the contact information
on the [maintainer's GitHub profile](https://github.com/Dinil-Thilakarathne).

Please allow time to reproduce and assess the report before public disclosure. The maintainer will
coordinate disclosure and credit with the reporter when appropriate.

## Scope

Relevant reports include vulnerabilities in the published packages, unsafe host-page interaction,
cross-origin or data exposure, dependency compromise, and release-pipeline security. General support
requests and non-security bugs should use the public issue templates.
